## Audit conclusions and implementation order

1. **Role and ownership security:** finish the canonical roles, server-side authorization, role-change invalidation, and owner-scoped customer queries first. No role or ownership requirement is considered complete until its integration tests pass.
2. **Data/API integrity:** audit all eight entities and CRUD contracts, then document the actual PostgreSQL schema and migration approach.
3. **UI completeness:** retain Thymeleaf, close verified module and accessibility gaps, and supply responsive prototypes.
4. **Additional infrastructure:** design and test MongoDB, RabbitMQ, OAuth2, and deployment separately. MongoDB and RabbitMQ are not present today; OAuth2 credentials are not available in the repository. Their live operation must not be represented as verified until configured and tested.
5. **Delivery:** add reproducible API/security/UI checks and finish README and assignment evidence from actual results.
